# Otto AI Plugin

This repository contains Otto AI plugin distributions for Claude and ChatGPT.

## Structure

```text
common/
  assets/
  skills/
plugins/
  claude/
    .claude-plugin/
      plugin.json
    .mcp.json
    LICENSE
    README.md
    assets/
    skills/
  chatgpt/
    plugin.json
    mcp.json
    assets/
    skills/
    extensions/
```

`common/` is the shared source for assets and skills. The `plugins/claude` and `plugins/chatgpt` folders are committed and regenerated by scripts.

## Build

Generate both plugin distributions:

```bash
npm run build
```

Generate one distribution:

```bash
npm run build:claude
npm run build:chatgpt
```

Create a ChatGPT upload ZIP:

```bash
npm run zip:chatgpt
```

## Claude

Validate the Claude plugin from repo root:

```bash
npm run validate:claude
```

Submit with plugin path:

```text
plugins/claude
```

The Otto MCP connector should also be submitted/tracked separately:

```text
https://mcp.joinotto.com/mcp
```

## ChatGPT

Upload either the `plugins/chatgpt/` folder contents or the generated ZIP:

```text
otto-ai-chatgpt-plugin.zip
```

## MCP Server

Both distributions point to:

```text
https://mcp.joinotto.com/mcp
```
